## 😩 每个家长的崩溃时刻

晚上 8 点，孩子还在磨蹭。

> "作业写完了吗？"
> "快了快了。"
> "你半小时前就这么说的！"

这样的对话，每天都在无数家庭上演。

不是孩子不听话，而是**他根本不知道"做完作业"这件事有多重要**——没有即时反馈，没有成就感，只有一遍又一遍的催促。

直到我给自己的小孩做了一个小工具，一切都变了。

---

## 🎯 这就是「作业打卡系统」

一个极简的 Web 应用。**家长设定任务，孩子点一下"完成"，系统自动记录。**

就这么简单。但效果出乎意料。

---

### 🔥 孩子竟然主动打卡了

- **2 次点击完成打卡** — 选任务 → 点完成，比刷短视频还简单
- **🔥 连续打卡** — 每天看到火苗越来越旺，根本停不下来
- **⭐ 质量星级** — 孩子自己评价作业质量，学会自我反思

### 📊 家长看得清清楚楚

- **完成率趋势图** — 最近一周 / 一个月，哪科一目了然
- **科目维度分析** — 语文好、数学弱？数据说话
- **月度日历热力图** — 像 GitHub 贡献图，绿色越多越骄傲

### 🏃 运动和习惯也能管

不光是作业。跳绳、练字、读书打卡……只要是习惯，都能记录。

## 🆕 v0.4.0 新功能

### 📅 月历课程表

一眼看整月。🏫 学校课程（蓝色）和 📚 补习班（橙色）按日期排列，清清楚楚。

- 每周重复课程自动排好
- 单次课程单独标注
- 远程课可填写上课 App（腾讯会议 / 钉钉课堂），消息里自动标注
- 点击日期就能新建，点击课程块就能编辑

### 🔔 自动提醒（双重保险）

**提前 1 天**：明天有数学补习班，今晚弹通知

**提前 30 分钟**：体育课还有 30 分钟，准备出发

浏览器通知 + 应用内横幅双通道，不会漏。

### 📲 钉钉推送（v0.4 主打）

家里有钉钉群的家长，这个功能太省心了——**什么都不用做，消息自己来**：

- **每日课表（每天早上）** — 今天有什么课，几点上，自动发到群里
- **未来 7 天总览** — 一次看清一周的课程安排，按日期分组、标注星期
- **上课前 1 小时提醒** — 提前提醒孩子准备，不再临时抓瞎
- **学习任务推送** — 每天 07:00 今日任务清单、21:00 今日完成总结（完成率 + 积分）、每周日 22:00 本周总结（打卡天数 + 分科目分布）
- **手动推送** — 设置页一键补发，改完课程立刻知道效果

> 设置页填入钉钉群机器人 webhook 即可开启，一条消息都不丢。

## 🛠 为什么推荐？

| 市面常见痛点 | 这款工具 |
|:---|:---|
| 要注册、要绑定手机号 | 零配置，打开就用 |

## 💻 技术栈

```bash
npm install
npx prisma db push
npm run dev
```

打开 <http://localhost:5173>，搞定。

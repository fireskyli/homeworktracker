## 版本一（完整版，约 400 字）

给小学生做了个免费的作业打卡工具，用了 3 个月，孩子从"催着写作业"变成"主动打卡"了 🔥

📌 家长设定任务，孩子点一下"完成"就打卡，2 秒搞定
📊 完成率趋势、科目分析、月度热力图，哪科弱一目了然
🏃 跳绳、练字、读书这些习惯也能记录打卡
📅 月历课程表，学校课和补习班一目了然，每周重复自动排好
🔔 提前 1 天 + 提前 30 分钟自动提醒，不靠吼
📲 新版还支持钉钉推送：每天早上自动发今日课表、上课前 1 小时提醒、晚上发今日完成总结，家长群消息自己来

开源、免费、零广告，数据都在自己手里，Web 网页手机电脑都能用，无需注册装 App。

部署也简单：本地 `npm run dev` 一分钟跑起来；想云上部署，Railway / Render / Docker 都有教程。

GitHub：https://github.com/fireskyli/homeworktracker

## 版本三（程序员版，约 250 字）

给娃做的作业打卡工具开源了，自用 3 个月，效果出乎意料：

- React 18 + Express + TypeScript，SQLite/PostgreSQL 双模式
- 打卡、连续天数、完成率报表、月度热力图
- 课程表月历 + 浏览器/钉钉双通道提醒
- 191 个测试用例全覆盖，Vitest + supertest 集成测试
- 单机模式零配置开箱即用，网络模式支持多家庭

孩子从被动催作业变成主动打卡，积分兑换、运动打卡也都安排上了。
